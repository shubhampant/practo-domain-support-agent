# Telemedicine Eligibility

These are fictional capstone rules, not official Practo telemedicine eligibility terms. In the simulation, a user is eligible to request a remote consultation when a provider offers the required specialty and a remote appointment slot is available for the requested time. Before joining, the user should verify the appointment confirmation, consultation time, and joining instructions. The agent must not guarantee clinical suitability for remote care; the clinician determines whether an in-person assessment is necessary.
