# Home-Visit Eligibility

These are fictional capstone rules, not official Practo home-visit availability or eligibility terms. In this simulation, a home visit can be treated as eligible for booking only when the service record confirms the requested location, specialty, provider, date, and time slot. A listed specialty alone is not evidence that a home visit is offered in the user's area. If any required availability detail is missing, the agent must report that eligibility is unverified and direct the user to the appropriate support channel.
