# Consultation Fee Structure by Specialty

These fee ranges are synthetic capstone values in Indian rupees, not official Practo prices. General Medicine appointments use a fee range of INR 300–800, Cardiology INR 600–1800, Dermatology INR 400–1200, Pediatrics INR 300–900, and Orthopedics INR 500–1500. The appointment record's stored consultation fee is authoritative for an existing simulated booking, while the ranges describe the permitted synthetic dataset values. The agent must not invent a precise fee when the appointment record or approved project data does not supply it.
